# Lane: m2 (the M2 check for freeze winners)

Goal: a fast, exact M2 check of each freeze winner and the integrated branch: forces gate against an M2 base baseline, interleaved A/B against base (Metal single and mixed, 8 tests, 2 rounds of 15 s), peak memory per run. Everything lives on the M2 under ~/lab/ultra-m2; lab copies of the scripts are in experiments/028-ultra-max/m2/.

## How to check candidates (laptop)

    /Users/amir/code/mini/openmm-metal-lab/experiments/028-ultra-max/m2/m2cand.sh /Users/amir/code/mini/hipdelta-gbsa <commit> [<commit>...]

It syncs, builds each tree on the M2, runs one check session, waits and prints the summary. `-r 1 -s 5 -t gbsa,pme` gives a smoke run. The M2 side by hand: m2sync.sh from the laptop, then on the M2 `/bin/sh -c 'nohup /bin/sh -c "/Users/amir/lab/ultra-m2/tools/m2build.sh /Users/amir/lab/ultra-m2/cand && /Users/amir/lab/ultra-m2/tools/m2check.sh /Users/amir/lab/ultra-m2/cand" > /Users/amir/lab/ultra-m2/checks/run.out 2>&1 < /dev/null &'`.
