The only repeatable failure is testLargeForces (TestLocalEnergyMinimizer.h:229). It is an upstream issue on M3 GPUs and fails on unmodified OpenMM with OpenCL. The other failures are stochastic tests that pass on rerun.

Limits

  • No df64 transcendentals. Using one on a mixed value is a compile error, which Folding@home's path never triggers.
  • QTBIntegrator is single precision only. There is one GPU per context.
  • Requires macOS 15 or later and an M1 or newer GPU.
  • Not yet run: OpenMM's standard benchmark suite, and M1 or M4 hardware.

Method

Buildgit archive of f9347f6c5 on each machine; source manifest sha256 matches. Apple clang 21.0.0, Release
