AI disclosure: this work was done by Claude Fable 5.1, with Gemini 3.8 writing harness code under its direction, on my machines. Every number comes from code that ran on the hardware named. Nothing here is proposed for inclusion in OpenMM.

I measured the Common Compute kernels as Metal against Apple's OpenCL on an M2 (10 GPU cores) and an M3 Ultra (60), macOS 27, apoa1 inputs captured from a real OpenCL run. Harnesses and captures: https://github.com/RedesignedRobot/openmm-metal-lab

Results match. Integrator 99.98% of values bitwise identical, bonded energy within 17 ppb, nonbonded forces within 8 ppm of the largest force, PME kernels within 0.54 ppm, neighbour list and sort identical. This needs `mathMode = .safe`; fast math does not match.

Speed, same clock on both sides:
- Straight translation ties OpenCL: PME kernels, VkFFT (runs on Metal through metal-cpp), sort, reductions, per-step host cost with one encoder per step.
- findBlocksWithInteractions rewritten with `simd_ballot` and friends: 2.3x faster on the M2, about 3x on the M3 Ultra, same pairs.
- computeNonbonded rewritten natively: 1.68x faster on the M3 Ultra, 8 to 11% slower on the M2. The M2 loss is all in the exclusion tile loop and I could not remove it.

Things that may save someone time:
- @peastman's program-scope `uint LOCAL_ID [[thread_position_in_threadgroup]];` needs MSL 3.1, so macOS 14. All 26 programs build under 3.1 to 4.1. @NORPG, your branch compiles as 3.0.
- MSL has no `erf` or `erfc` in any version. `1 - erf(x)` is useless from x = 4. Single precision inlines its own approximation, so only double paths care.
- Runtime compile costs the same as OpenCL, about 0.7 s cold and under 1 ms warm. No offline compiler without Xcode.
- There is no GPU watchdog. A runaway kernel was still running after 120 s, and an out-of-range write reports no error.
- SIMD width is 32 on both chips and `thread_index_in_simdgroup` equals local id mod 32 for threadgroups of 32 to 512.
- Apple's OpenCL profiling events are in mach ticks, not nanoseconds.

So a Metal platform is a like-for-like replacement for the deprecated OpenCL one, with a faster neighbour list, not a general speedup. Happy to run anything on these two machines if it helps.
