# Saturate float to fixed point conversions in OpenCL

Fixes #5434.

On Apple M3 GPUs, converting an out-of-range float to `long` wraps modulo 2^64 instead of saturating. Huge forces became 0, so the minimizer's overflow check never fired and `testLargeForces` stopped at its starting point.

- `realToFixedPoint` in common.cl now uses `convert_long_sat`.
- Kernels that converted forces with a plain cast now go through `realToFixedPoint`: customCppForce, pythonForce, atmforce, customCentroidBond, customCVForce, the minimizer's constraint forces, RPMD contraction and `reduceReal4Buffer`.

In mixed precision, the minimizer's constraint forces and the RPMD contraction now round to float before conversion, like every other force.

Tested on an M3 Ultra: all 66 OpenCL tests pass, including `TestOpenCLLocalEnergyMinimizerSingle`, which fails on master.
